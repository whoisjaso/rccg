# Image brief: precision prompts

Each section below is one image for the site. The **paste-ready prompt is in the grey box**: copy the whole box into ChatGPT (image generation) in one go. It already includes face protection, camera, lighting, composition, colour and what to remove.

## Every time
1. **Upload two images:** the **source photo** named in the section, and **`style-site-hero.png`** (the style reference).
2. Paste the whole prompt box.
3. If anything is off, reply with one correction at a time, for example "The man's face changed. Restore his exact face from the source photo and change nothing else." Small, specific corrections work far better than a fresh prompt.
4. Send me the result in chat, saying which number it is. I'll size it, check the crop and put it on the site.

## How the site uses these images (why the prompts specify placement)
- **Opening slides (#1 to #4)** are wide, 16:9. On a computer the headline and button sit in the **lower-left third**, so that area must be calm, dark and empty. On a phone the site crops the image to a tall strip around the **right-centre**, so faces must sit between 50% and 75% of the frame width.
- **Portrait spreads (#5 to #8)** are 4:5 and sit next to text on a white page, so the backgrounds need to be clean and quiet.
- **Bands (#9, #10)** are very wide, 21:9, with text on the left third.
